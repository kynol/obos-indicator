# OBOS · 综合超买超卖指标

[English](README.md)

用于 TradingView 的 Pine Script v6 副图指标。将 RSI、Stochastic、CCI 和 Bollinger %B 合成为 0–100 的状态分数，并结合趋势、波动和恢复条件生成警报。

这是一个市场状态分析与研究工具，使用 `indicator()`，不包含自动下单、完整进出场策略或策略收益报告。本仓库不承诺胜率或盈利表现。

## 安装

1. 打开 [OBOS.pine](OBOS.pine)，选择 **Raw**，复制完整源码。
2. 在 TradingView 图表中打开 Pine Editor，新建指标脚本，用源码替换编辑器内容。
3. 保存脚本，点击添加到图表。该指标显示在独立副图中。
4. 在指标设置里选择周期预设，检查参数后再使用。

GitHub 用于保存和分发源码；本仓库没有 TradingView 社区脚本发布链接。

## 综合分的构成

| 分量 | 处理方式 | 默认权重 |
| --- | --- | ---: |
| RSI | 使用 RSI 数值 | 35 |
| Stochastic | 使用 Stochastic 数值 | 20 |
| CCI | `50 + CCI / 4`，限制在 0–100 | 20 |
| Bollinger %B | 相对布林带位置乘以 100，限制在 0–100 | 25 |

综合分由权重归一化后计算，并按设置进行 EMA 平滑。数据不足时分数可能为空。

默认参考线为 20（严重超卖）、30（普通超卖）、50（中轴）、70（普通超买）、80（严重超买），可以在设置中调整。

## 图形应该怎样理解

- **OBOS 曲线**：综合分经过额外的显示平滑；默认先做 6 周期 EMA，再做 2 周期 EMA。
- **绿色／红色填充**：显示曲线低于严重超卖线／高于严重超买线时出现。
- **曲线颜色**：由内部 `score` 相对严重超买／超卖阈值的位置决定。
- **黄色背景**：布林带宽度、ATR% 和 EMA 间距的收敛投票及持续条件满足时出现，属于视觉提示。

**显示曲线 `displayScore` 与信号使用的内部 `score` 不同。** 显示平滑会带来额外延迟；曲线位置、曲线颜色和警报不一定在同一根 K 线上变化。

## 超卖状态与恢复信号

**“处于超卖区时买入”与“向上恢复警报触发时买入”是不同的操作规则。** 本脚本不会在每一根超卖 K 线上直接触发买入信号。

恢复条件会检查待确认状态、确认窗口、价格、动量、冷却以及启用的环境模块，再进入两类逻辑：

- 趋势回调：检查趋势上下文、回调深度和恢复结构。
- 均值回归：检查极端程度、市场状态、恢复结构及保护条件。

两类逻辑分别计算质量分，并在均满足条件时选择相应通道。增强信号还需要更高的质量和上下文条件。

**Q 是脚本内部的质量评分，不是胜率、概率或经过校准的收益预测。** 当前视觉层绘制曲线、填充和背景；恢复信号通过警报输出，没有绘制 BUY/SELL 箭头。

## 周期与市场设置

- 提供自动、5m、15m、1H、4H 和自定义预设。支持选择预设不代表已证明所有周期都有相同表现。
- 默认设置包含美股日内交易环境逻辑，例如仅常规交易时段发信号、同时段 ATR/RVOL 基线和异常振幅保护。
- 高周期上下文必须严格高于图表周期，否则脚本报错。高周期请求使用已结束的高周期数据，会产生等待确认的延迟。
- ATR、成交量、Regime、价格、动量等设置会影响信号条件；成交量模块默认关闭。
- 用于其他市场或交易时段前，应检查相关设置与数据可用性。

## 创建警报

在 TradingView 创建警报，选择此脚本，再选择 `Upward Recovery`、`Downward Recovery` 及对应的 `Enhanced` 条件。源码中的静态警报名称保留 `OBOS V9.2`。

如需动态消息，启用 `Enable dynamic alert messages`，并选择脚本的 `Any alert() function call` 条件或界面中的对应翻译。动态消息包含标的、周期、通道、Q、价格和时间等信息。仅把脚本加到图表上不会自动创建警报。

`Confirm on close only` 默认开启。关闭后盘中条件和警报可能变化，使用者应明确区分盘中状态与收盘结果。

发布版的参数名、选项、图形标题、错误提示、警报和注释已统一为英文。中英文原版的选项在全部引用位置同步替换；未修改计算公式、阈值、状态机或绘图样式。原有图表模板或警报可能需要重新检查和创建。
